## Decisiones vigentes

Tres departamentos: Consultoría, Comercialización y Renta. Motorreductores y Productos industriales son categorías comerciales. El correo es el único medio de contacto; no hay formularios, teléfono, WhatsApp ni envío desde el servidor. El diseño utiliza la V dorada sin fondo junto a la palabra Versátil integrada al sitio.

Las decisiones posteriores del usuario prevalecen sobre propuestas iniciales del PDF de referencia. Los documentos describen el código implementado; los pendientes no se presentan como funciones ya disponibles ni como datos verificados de la empresa.
